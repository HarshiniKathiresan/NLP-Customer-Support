# NLP Customer Support System

## About the Project
This project uses Natural Language Processing (NLP) and Machine Learning to classify customer inquiries and suggest appropriate responses automatically.
The goal is to improve customer support efficiency by identifying customer concerns and providing response suggestions.

## Problem Statement
Customer support teams receive many inquiries daily. Manually categorizing and responding to every inquiry can take significant time.
This project helps automate inquiry classification and response suggestions.

## Objectives
- Automatically classify customer inquiries.
- Identify common customer concerns.
- Suggest appropriate responses.
- Evaluate machine learning model performance.
- Improve customer support efficiency.

## Technologies Used
- Python
- Natural Language Processing (NLP)
- Scikit-learn
- TF-IDF
- Logistic Regression
- Pandas
- Streamlit

## Dataset
Bitext Customer Support Training Dataset.

## Project Workflow
1. Dataset collection
2. Data preprocessing
3. Text vectorization using TF-IDF
4. Model training using Logistic Regression
5. Model evaluation
6. Customer response suggestions

## Features
- Customer inquiry input
- Automatic inquiry classification
- Prediction confidence
- Suggested customer responses
- Interactive web application

## How to Run the Project
Install the required libraries:
pip install streamlit pandas scikit-learn joblib matplotlib

Run the application:
python -m streamlit run app.py
